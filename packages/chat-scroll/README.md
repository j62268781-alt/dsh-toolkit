# 聊天滚动优化

在 DSH `0.2.2-rc.5` 的长会话中，保留视口前后约三屏的内容，并用等高占位保留远处行的滚动位置和原生跳转锚点。首尾各八行始终挂载。按 `⌘F` 或 `Ctrl+F` 会恢复已加载的正文，重新打开会话后继续优化。

在 Toolkit 的插件管理里启用 `dsh-toolkit-chat-scroll`。若已启用旧本地包 `@local/dsh-chat-scroll`，先停用旧包，再启用 Toolkit 的组件。独立安装时，使用构建后的本目录。停用组件可恢复原生渲染。

组件依赖 rc.5 的原生聊天槽位和组件结构。Host 历史数据、翻页与存储由 DSH 管理。
