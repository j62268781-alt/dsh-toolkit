# 工作树（Worktrees）

可随 `dsh-toolkit` 聚合包启用，也可单独安装 `dsh-toolkit-worktrees`。入口是「设置 → 工作树」，不依赖 Git 设置模块。原来在 Git 设置中写入的配置无需迁移：新页面仍读取同一条 DSH 原生配置。

- 路径相对于仓库主检出目录。在设置里清空目录并移出焦点，会恢复 DSH 的原生默认（当前为 `.agents/worktrees`）；修改目录不会迁移旧工作树。
- 名称前缀用于原生工具的自动命名。
- 归档保留开关直接对应宿主的 `retainOnArchive`。关闭时原生归档流程可能清理工作树，但不会创建备份。
- 受管列表按仓库分组，只显示 DSH 会话的原生创建记录。打开或刷新列表时会检查记录中的目录是否仍存在；状态不代表 Git 注册、文件是否干净或是否可安全删除。手动创建的工作树不在列表中。
- 可以跳转到未归档的创建会话；已归档的会话只标记状态，不会因查看列表而取消归档。
- 「检查清理条件」按需核实单个受管工作树，显示当前是否符合条件及阻止原因。检查不会删除或修改工作树，结果也不是后续删除的授权。

若原生配置或列表不可用，请检查 DSH 是否启用了 **Change requests & worktrees**。本模块不新增 Agent 工具；创建仍走 DSH 原生入口。创建前 Fetch、按量回收、手动删除确认、备份与通用恢复入口尚未实现。
