# Procedural pet artwork

`deepseek-whale/` holds the DeepSeek Whale sprite sheet (768×936, 8 columns × 9 rows of
96×104 cells). It is drawn by this repository's own procedural painter
(`tools/pet-painter/whale.py` for the side view, `front.py` for the front view, `sheet.py` for the animation grid) and the manifest
declares CC0-1.0.

The four demo pets that shipped earlier (from Qoder Desktop Pet Lab) were removed on the
user's request; their procedural artwork was CC0-1.0 as well. The runtime still implements
sprite frame timings and island geometry from the supplied behavioral documentation; no
source from `dsh-pet` or Qoder's own pet artwork is copied.
