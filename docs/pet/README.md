# 桌面宠物与灵动岛

`dsh-toolkit-pet` 提供桌面悬浮宠物和屏幕顶部灵动岛。两种窗口共用所选形象，可以分别开启；初始均关闭。配置通过 DSH 设置表单保存，运行中的窗口接收实时更新。

## 使用

构建并加载插件后，打开「设置 → 桌面宠物」，选择形象，再开启悬浮宠物或灵动岛。首次使用会下载并准备 Electron 运行时，也可以先点击「准备桌面运行时」。准备或启动失败时，设置页会显示原因并提供重试。桌宠由插件管理，无需手动启动另一款桌宠软件。

桌面悬浮支持拖动位置、调整宠物大小和会话气泡宽度。灵动岛支持独立调整收起尺寸、空闲时保留显示，以及在其他显示器上同步显示。各屏幕共享会话内容，鼠标悬停、展开和收起只作用于当前窗口。按住胶囊拖动可以移动窗口：桌宠能拖到任意屏幕，灵动岛只在它自己的屏幕内移动，位置按显示器记住（写在 `~/.dsh/toolkit/pet/layout.json`，重启后仍在原处），拖动超过 4px 不会触发点击。收起态左侧是所选形象，右侧是一枚状态徽标：`正在工作`（绿，转圈）、`需要你处理`（橙，`!`）、`有新结果`（蓝，`✓`）、`失败`（红，`×`），多个会话时数量进入悬停提示；没有会话活动时显示 `hi~` 问候，此时悬停不会自动展开。徽标文案决定胶囊宽度（收起态在 212–280px / 有刘海屏 360px 区间内自适应），仍受「灵动岛宽度」百分比约束。

展开态按 Qoder 的内容模型分两种互斥形态。排在首位的会话正在执行、且整份列表没有待处理事项时，显示「运行中列表」：最多三行，每行是两行文字（标题、`状态短语 · 摘要`），两行都单行省略，没有头像、没有按钮、没有输入框，也不出现滚动条。其余情况显示「单会话详情」：标题与状态短语（`正在执行` / `等待你的处理` / `本轮已完成` / `本轮执行失败`）加右侧相对时间（`刚刚` / `5 分钟前`）、最多三行的说明；有待办时在说明下方内联待办块（审批为橙色、提问为青色，带命令或问题原文）。两种形态都不是「先用鼠标选中、再点按钮」，而是整行 / 整张卡片本身就有 hover 高亮，鼠标移上去直接点一下就能打开对应会话，打开成功后灵动岛随即收起。点开即视为「已读」：该会话立刻从实时活动里消失、徽标随之回落，直到它再次产生新动作；已读记录写在 `~/.dsh/toolkit/pet/seen.json`，重启后不会重复提醒。从别处进入同一个会话同样算已读：系统通知点击跳转、或在应用里切到目标会话时，客户端半部读既有会话列表快照里的 `retainedBy.mainView`，一发现主视图换了会话就向 host 上报一次 `seen`（同一个会话重复渲染只报一次），灵动岛状态随即刷新。从别的应用切回 DSH 也算「看过了」：客户端只在窗口真的在前台（`visibilityState === 'visible'` 且窗口有焦点）时才上报，一次激活会把岛上针对当前会话的「有新结果」一并清掉；窗口失焦或隐藏期间不报，提醒照常保留。实时活动本身也只保留近期内容——结束或暂停的会话留 30 分钟、判定为正在执行的留 6 小时（防止崩溃残留的 `running` 占位），等人的审批与提问不受时间限制。

待审批或待回答时，整张卡片同样只负责打开原会话处理：宿主当前没有公开的批准 / 回答接口，灵动岛不会代你 approve 或 deny，审批仍由会话里的 answerer 决定。胶囊在收起态点击或悬停 300ms 展开；鼠标移出窗口会立即收起，窗口失焦时同样收起；展开时胶囊本身不再响应点击，避免挡住内容。桌宠气泡保留原来的卡片列表，卡片下方仍可直接输入补充要求，输入时保持展开。

macOS 上，有刘海的屏幕通过 `NSScreen.safeAreaInsets` 和刘海两侧的可用区域取得真实几何位置，黑色窗口贴住屏幕顶边，状态位于刘海两侧，展开内容放在刘海下方。展开面板按 Qoder 的面板尺寸展开（刘海屏 590px、普通屏 552px，屏幕更窄时按屏宽留 120px 封顶），收起态那点宽度装不下内容，也装不下与摄像头区并排的徽标。可见的黑色面板在刘海模式下收起态左右各内缩 6px、展开态内缩 19px 肩部，因此胶囊里的形象与徽标跟着让位（收起 `padding-inline:18px`、展开 31px），距可见边缘分别回到 12px 与 16px；展开内容的左右内边距相应改为 39px（肩宽 19 + 20），行与卡片再各自外扩 8px 作为 hover 高亮，因此文字距可见边缘 20px、高亮块 12px，不再贴边。摄像头所在的实体区域没有可绘制像素，窗口只能围绕它与黑色背景连成一体。没有刘海的屏幕顶部是菜单栏，胶囊挂在菜单栏下方（`workArea.y` 再留 6px），不会压住状态栏图标；系统几何数据不可用时也使用这一布局。此窗口由工具箱创建，不会接管 Apple 的实时活动或系统菜单栏控件。

## 配置

聚合工具箱和独立包都使用相同的模块配置字段，安装为聚合包不会改变已有宠物设置。更早的兼容入口曾将这些字段放在 `pet` 命名空间中。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `activePet` | `qoduck-lab` | 两种窗口共用的形象 ID |
| `petEnabled` | `false` | 显示桌面悬浮宠物 |
| `petSize` | `100` | 宠物大小百分比，50–100 |
| `bubbleWidth` | `280` | 会话气泡宽度，240–480 像素 |
| `islandEnabled` | `false` | 显示屏幕顶部灵动岛 |
| `islandIdle` | `true` | 空闲时保留灵动岛 |
| `islandAllDisplays` | `true` | 在其他显示器上同步显示 |
| `islandWidth` | `100` | 灵动岛收起宽度百分比，75–150 |
| `islandHeight` | `100` | 灵动岛收起高度百分比，75–150 |
| `electronPath` | 空字符串 | 指定现有 Electron 可执行文件的绝对路径 |

`DSH_TOOLKIT_ELECTRON_PATH` 也可指定可执行文件。运行时未指定时，插件使用 Electron 43.3.0，按平台与架构缓存在 DSH 数据目录下的 `toolkit/pet/electron` 中。Host 启动辅助进程前会清除 `ELECTRON_RUN_AS_NODE`，确保 Electron 创建图形窗口。

## 运行方式

Host 模块订阅会话状态，汇总活动并向设置页和辅助进程推送更新。设置页使用 DSH 鉴权路由；辅助进程通过独立的回环地址和随机令牌连接，使用自身的 Electron 主进程创建透明、无边框、置顶窗口。辅助进程随插件退出，并监测 Host 生命周期。

此实现不依赖 DSH 私有 Electron IPC 或修改 DSH 安装文件。Host 必须运行在有桌面会话的本机；远程或无图形环境的 Host 无法将这些窗口显示到浏览器所在的电脑。点击返回工作台需要有连接着的 DSH 页面接收导航事件。

## 资源与范围

内置 `qoduck-lab`、`kleidis-lab`、`neon-cat` 和 `retro-duck` 四套精灵资源，来自本地演示项目的原创程序绘制素材，各资源清单声明为 CC0-1.0。插件代码采用仓库 MIT 许可。未使用 Qoder 官方宠物美术或 `dsh-pet` 的受限素材。

当前版本使用内置形象，不含官方在线 Petdex、语音输入或触觉反馈。macOS 使用 AppKit 的真实安全区域数据识别刘海；其他平台和无刘海显示器使用独立胶囊布局。平台对窗口置顶、全屏空间和多显示器的处理可能不同，需在对应桌面系统上实测。

外观参考 [Apple Live Activities 设计指南](https://developer.apple.com/design/human-interface-guidelines/live-activities)，刘海定位依据 [NSScreen.safeAreaInsets](https://developer.apple.com/documentation/appkit/nsscreen/safeareainsets) 与两侧可用区域。布局采用纯黑背景、两侧内凹肩部与刘海拼接、右侧文字徽标和下方展开内容，展开态沿用工具箱的两形态会话视图（运行中列表 / 单会话详情 + 待办内联）；徽标、两形态与配色参考 Qoder CN 灵动岛的内容模型。

会话状态采用实时事件和现有投影视图。插件加载前已经等待的批准，以及历史失败记录，当前无法完整恢复；新产生的批准和问题会显示为待处理，并引导到原会话操作。宿主没有公开的批准 / 回答接口，批准只能由会话内的 answerer 决定，因此灵动岛与桌宠气泡都只提供「打开会话」入口，不会在岛内直接批准或回答。
