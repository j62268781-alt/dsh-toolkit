能不能用一个插件把界面换成 Codex 那样？左边一条 icon 栏，右边工作区。

能，而且不用动内核。DSH 的界面颜色全部来自一组 --dsw-* 设计令牌， 客户端插件只要能往页面里塞一份样式表，就能把它们整套换掉。

● 运行了命令 · 读取 asar 里的客户端包

ctx.effect(() => {
  const tag = document.createElement("style");
  tag.textContent = CSS;
  document.head.appendChild(tag);
  return () => tag.remove();
}, "dsh-shell-kit:stylesheet");

侧栏那条 52px 的 icon 轨道不是新加的一列 —— 三栏栅格是内核固定的 （sidebar | main | rightbar）。做法是把侧栏自己重排成两列， 外壳一根线都不用改。
